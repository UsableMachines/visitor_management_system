Getting Started

Learn how to set up and use the Visitor Management System

Overview Prerequisites First Launch Register Visitors Check In / Out Watchlist AI Analysis Next Steps
1

What Is This App?

The Visitor Management System (VMS) is a complete platform for managing visitors at your facility. It handles visitor registration, host notification, badge issuance, watchlist screening, AI-powered risk analysis, and full audit logging — all with multi-tenant support and role-based access control.

2

Prerequisites

To get started, you need:

  • A user account (register on the login page or contact your admin)
  • An assigned role (Front Desk, Security, Host, Org Admin, or Super Admin)
  • For AI analysis: KINDO_API_TOKEN and KINDO_AGENT_ID environment variables configured by your administrator
3

First Launch

After logging in, you'll land on the Dashboard. This shows today's visitor counts, currently checked-in visitors, pending pre-registrations, and a list of recent visits. The sidebar provides navigation to all sections of the system.

Default admin credentials: admin / admin. Change the password immediately after first login via the Profile page.

4

Register Visitors

Click Register Visitor from the Dashboard or navigate to Visitors → Register. Fill in the visitor's details, select a host, and specify the purpose of the visit. The visitor will be automatically screened against the watchlist upon registration.

5

Check In / Check Out

When a visitor arrives, open their visit and click Check In. A badge is automatically issued and the host is notified. When the visitor leaves, click Check Out to mark them as departed and return their badge.

If a visitor has a high or exact watchlist match, check-in is blocked until a security review clears them or denies entry.

6

Watchlist Screening

Security and admin users can manage the watchlist under Watchlist. Add individuals who should be flagged or denied entry. Severity levels (high, medium, low) determine whether check-in is blocked or just flagged.

7

AI-Powered Risk Analysis

On any visit detail page, click Run Analysis to send visitor data to the Kindo AI enrichment agent. The agent returns a risk score, risk level, detailed findings, and recommendations. Results are saved to the visit record for future reference.

This feature requires KINDO_API_TOKEN and KINDO_AGENT_ID to be configured. If not set, a configuration message is shown instead.

8

Next Steps

Explore these additional features:

  • Badges — Track all issued badges and report lost ones
  • Audit Log — Review a complete history of all system actions
  • Admin — Manage users, roles, and organizations
  • Notifications — Stay updated on visitor activity (click the bell icon)
  • Dark Mode — Toggle the theme using the moon/sun icon in the top bar
  • Help — Click the ? icon on any page for context-specific guidance
